Janta Medical Store: website kaise chalayein

Website ka sara roz ka kaam Google Sheet se hota hai. Code kholne ki zarurat nahi.

1. Ek baar ka setup (10 minute)

  1. Drive mein janta-medical-sheet-template.xlsx upload karein, kholkar File → Save as Google Sheets karein.
  2. Do tab hain: Stock aur Blog.
  3. Share button dabao → General access → Anyone with the link → Viewer → Done. (Sheet mein sirf dawa/blog ka data rakho, koi personal data nahi.)
  4. Stock tab kholo, browser ke address bar ka poora link copy karo (https://docs.google.com/spreadsheets/d/…/edit?gid=…) aur config.js mein sheetCsv:"" ke andar daalo.
  5. Blog tab kholo, uska alag link copy karke blogCsv:"" mein daalo (dono ka gid alag hota hai).
  6. Purana tareeka (Publish to web → CSV) bhi chalta hai, par wo file se kholne par kabhi-kabhi "Failed to fetch" deta hai.
  7. config.js hosting par upload kar do. Bas, ab sab kuch Sheet se chalega.

2. Roz ka kaam: dawa ka stock

  • Dawa khatam hui to Stock tab mein Available ko No, aayi to Yes. Phone ke Google Sheets app se bhi ho jata hai.
  • Price mein sirf number likho, jaise 15. Website par apne aap ₹ 15 dikhega. Khali chhodo to daam nahi dikhega.
  • Nayi dawa: sabse neeche nayi line likho.
  • Pakka nahi pata to No rakho.

3. Roz ka kaam: ek blog / sehat salah

Blog tab mein neeche nayi line jodein:

  • Date: jaise 2026-11-02. Aage ki date likhoge to post usi din dikhegi (aap ek hafte ki pehle likh sakte ho).
  • Type (dropdown): Tip = sehat tip · Pehchan = bimari kaise pehchanein · Quote = doctor/sant ka vichar · Lekh = lamba lekh.
  • Title: heading (Quote ho to wahi vakya likho).
  • Details: baat likho. Har point nayi line mein - se shuru karo (nayi line = Alt+Enter).
  • By: kisne likha / kaha.
Dhyan: bimari ke lakshan likhte waqt aakhir mein "doctor ko dikhayein" zaroor likho. Dawa ki matra (dose) kabhi mat likho. Quote tabhi daalo jab aapko pakka ho ki wo usi ne kaha hai, galat naam se quote daalne se bachein.

Post 1-5 minute mein website ke "रोज़ की सेहत सलाह" section aur health-tips/daily.html par dikhti hai.

4. Kuch gadbad ho to

  • Sabse aasan jaanch: website ke folder mein check.html kholo. Wo Stock aur Blog dono link jaanch kar batata hai ki kya galat hai (link, tab, columns, date).
  • Website ke link ke aakhir mein ?debug=1 lagao (jaise index.html?debug=1). Search box ke paas likha aayega ki Sheet se kitni dawaiyan load hui.
  • "load nahi hui" likha ho to: link CSV format ka hai? Publish to web ON hai? Stock wali sahi tab publish hui hai?
  • Sabhi dawaiyan ek hi tab (Stock) mein rakho, alag-alag tab mein nahi.

5. Website ki files kab badalni padti hain?

Sirf tab, jab config.js (naam, phone, address, photo, reviews) badalna ho. Stock aur blog ke liye kabhi nahi.
